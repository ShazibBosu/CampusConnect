# CampusConnect Manual Test Plan

Primary owner: Tajwar Khan

1. Register a new student account and confirm automatic login.
2. Log out and log in again with the same account.
3. Edit the student profile and confirm the new information remains after refreshing.
4. Search study groups using a course code.
5. Create a study group and confirm the creator becomes its first member.
6. Join and leave a group using a second account.
7. Confirm a group cannot exceed its capacity.
8. Create and edit an event.
9. Submit and cancel an RSVP.
10. Log in as the administrator and review summary statistics.
11. Change a user role and verify access control.
12. Confirm a normal student cannot open the administrator API.
13. Test the interface at desktop and mobile widths.
14. Confirm invalid forms display understandable errors.
